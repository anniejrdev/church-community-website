# Church Community Website

A full-stack church community web application built to provide an online platform for managing church content, events, media, and community communication.

## 🚀 Features

- 🔐 User authentication
- 👤 User management
- 📝 Content management
- 📅 Event management
- 🖼️ Media gallery
- 📩 Contact forms
- 📱 Responsive design
- 🔗 REST API integration
- ☁️ Firebase integration
- 🗄️ Firestore database
- 🐛 Form validation and error handling

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Tailwind CSS
- React Router

### Backend & Database
- Firebase Authentication
- Cloud Firestore

### APIs & Services
- REST APIs
- Cloudinary

### Tools
- Git
- GitHub
- VS Code
